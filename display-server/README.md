# RID 监测智慧大屏（PC 端）

把 T-Display-S3 固件通过 **USB 串口（COM）** 连到电脑后，在浏览器里以
**智慧大屏**形式展示：中央**高德地图**实时标绘无人机/飞手位置与连线，
左侧**无人机列表**（型号/信号/ID/坐标），右侧**详细信息**（经纬度、
高度、速度、信号、BSSID、飞手距离等）。

```
┌──────────── 顶栏: 标题 · 连接状态 · 无人机数 · 有坐标数 · 信道 · 电量 · 时间 ────────────┐
│  左: 无人机列表         中央: 高德地图态势            右: 详细信息                     │
│  · DJI Mavic 3  -55dBm   [无人机标记+型号标签]         [暗红机型横幅]                 │
│  · DJI Mini 5 Pro        [飞手标记(绿) + 虚线连线]     信号/BSSID/UAS ID              │
│  · ...                   [点击标记选中]               飞机经纬度/高度/速度             │
│                                                        飞手坐标 + 与飞机距离           │
└──────────── 底部: 滚动信息 · 数据时间戳 ────────────────────────────────────────────────┘
```

## 一、快速开始

### 1. 烧录带串口上报的固件

大屏依赖固件通过串口输出 JSON 数据（每秒一行快照），**必须烧录新固件**：

```bash
cd E:\tdisplay-s3-rid-monitor-v1.0
pio run -t upload
# 或用合并镜像: esptool.py --chip esp32s3 --port COM5 write_flash -z 0x0 tdisplay-s3-rid-monitor-v1.0-full.bin
```

### 2. 安装依赖

```bash
C:\Users\19389\AppData\Local\Programs\Python\Python311\python.exe -m pip install -r requirements.txt
```

### 3. 启动服务（连接真实设备）

```bash
# 先确认串口号(设备管理器或 pio device list), 例如 COM5
python server.py --port COM5
```

看到 `[serial] 已连接` 后，浏览器打开：

```
http://localhost:8080/dashboard.html
```

### 4. 登录

正式版大屏需要登录后才能使用：

- 默认账号 **admin** / 密码 **admin123**（**部署前务必修改** `dashboard.html` 顶部
  `AUTH` 配置，纯前端校验，用于防止无关人员误操作）
- 登录状态在**当前浏览器会话**内保持（关浏览器后需重新登录）

### 5. 配置高德地图 Key（推荐）

地图需要高德 **Web端(JS API)** 的 Key（免费申请）：

1. 打开 https://lbs.amap.com → 注册/登录 → 「应用管理」→「我的应用」→ 创建应用
2. 添加 Key：服务平台选 **Web端(JS API)**，得到 **Key** 和 **安全密钥**
3. 编辑 `dashboard.html` 顶部两行：

```js
window._AMapSecurityConfig = { securityJsCode: "你的安全密钥" };
const AMAP_KEY = "你的Key";
```

4. 刷新页面即见地图。**不配置也能用**（列表/详情正常，地图区域显示提示）。

## 一·五、陌生无人机警报与白名单

正式版大屏内置**陌生无人机预警**：

- **发现陌生无人机**（MAC 不在白名单）→ 屏幕四周红色边框**闪烁** +
  顶部红色警报条 + **警报音**（WebAudio 生成，需页面有用户点击后才响，
  登录按钮点击即解锁）
- 同一架陌生机每个会话只响一次；**消失后再次出现会重新警报**
- 警报条两个按钮：
  - **加入白名单**：该无人机授权，不再警报（存入浏览器 localStorage，永久生效）
  - **忽略本次**：本次会话内不再对该机警报
- 列表/详情也可管理白名单：列表行有 🛡 标记；详情页底部"授权管理"区
  可**加入白名单 / 移除授权**（移除后该机重新视为陌生、触发警报）

## 一·六、飞行记录与轨迹线

正式版大屏内置**飞行记录**（左侧栏 Tab 切换「无人机列表 / 飞行记录」）：

- **实时轨迹线**：每架无人机在地图上以**淡蓝虚线**实时绘制移动路径
  （航点去重：静止超过 8 秒或坐标几乎不变时不重复记录，最多保留 300 个航点）
- **飞行记录列表**：无人机消失后自动生成一条记录
  （机型 / MAC / 起止时间 / 航点数 / 飞行时长），最多保留 50 条，
  存入浏览器 localStorage，**刷新页面不丢失**
- **查看轨迹**：点击某条记录 → 地图上以**橙色粗线**高亮该次飞行路径并自动缩放
- 会话判定：固件快照为全量数据，某 MAC 从快照中消失即视为本次飞行结束

## 一·七、统计 / 导出 / 回放 / 方向角

- **统计面板**（左侧「统计」Tab）：累计记录/今日发现/累计航点/平均时长 + 机型分布 TOP5 条形图
- **导出**（飞行记录 Tab 顶部）：
  - **GPX**：全部轨迹导出为 `.gpx`（可导入奥维/两步路等导航软件复盘路径）
  - **CSV**：记录汇总表（机型/MAC/起止时间/航点数/高度/速度）
- **动画回放**：点击记录「▶ 动画回放」→ 地图红色圆点沿轨迹移动 + 进度百分比
- **方向角**：列表行与详情页显示每架无人机**距监测点的距离与方位**（监测点 `MONITOR_LAT/LON` 在 dashboard.html 顶部配置，按部署位置修改）

## 二、演示模式（无设备预览）

### 方式 A：独立演示页面（推荐先看这个）

**直接双击打开 `demo.html`** 即可——零配置、零依赖、无需服务器，
**功能与正式版完全一致**（登录 / 白名单 / 陌生无人机警报）：

- **登录**：默认 admin / admin123（`demo.html` 顶部 `AUTH` 可改），
  登录后才启动演示数据
- **内置 10 架模拟无人机**（DJI 具体型号 + 道通/飞米/Parrot/Skydio/哈博森，含真实
  DJI SN 前缀与 IEEE OUI），在北京区域**实时飞行**（绕圈/悬停），带轨迹尾迹、
  RSSI 抖动、信道轮询、电量变化
- **陌生无人机警报**：登录后 10 架均为陌生 → 屏幕红闪 + 警报条 + 警报音，
  可「加入白名单 / 忽略本次」，行为与正式版一致
- **白名单**：列表 🛡 标记 + 详情页「加入白名单 / 移除授权」（localStorage 持久化）
- 地图默认使用**内置 Canvas 网格态势图**（离线可用）：经纬网格 + 刻度 + 比例尺 +
  无人机发光点 + 型号标签 + 飞手绿点 + 虚线连线 + 飞行轨迹，点击标记选中
- 配置了高德 Key 后自动切换为高德地图（**建议通过 server.py 托管访问**，
  即 `http://localhost:8080/demo.html`，file:// 下高德可能受限）

### 方式 B：服务演示模式（走真实数据链路）

```bash
python server.py --demo
```

浏览器打开 `http://localhost:8080/dashboard.html` 即可（8 架模拟数据经
WebSocket 推送，与真实设备同一条数据管道）。

## 三、参数说明

| 参数 | 默认 | 说明 |
|------|------|------|
| `--port` | COM5 | 串口号（连接固件） |
| `--baud` | 115200 | 波特率，与固件一致 |
| `--http` | 8080 | 大屏页面 HTTP 端口 |
| `--ws` | 8765 | WebSocket 数据端口 |
| `--demo` | 关 | 演示模式（无需串口） |
| `--interval` | 1.0 | 演示数据推送间隔（秒） |

大屏页面还支持 `?ws=端口` 指定 WebSocket 端口（多开/换端口时用）。

## 四、固件串口协议

固件每秒输出一行 JSON 全量快照（`src/main.cpp` 的 `serialReport()`）：

```json
{"t":"snap","n":3,"ch":6,"bat":78,"drones":[
  {"mac":"AA:BB:CC:00:11:22","model":"DJI Mavic 3","id":"1581F45QK9C2D12",
   "rssi":-55,"lat":39.9112,"lon":116.4210,"alt":120.5,"spd":8.2,
   "olat":39.9042,"olon":116.4074,"proto":0}
]}
```

| 字段 | 说明 |
|------|------|
| `n` / `ch` / `bat` | 无人机总数 / 当前侦听信道 / 本机电量(-1=USB) |
| `mac` | 发射方 BSSID（IEEE OUI→品牌识别依据） |
| `model` | 识别机型（DJI SN→型号 / 其他品牌 OUI→品牌） |
| `id` | 序列号 UAS ID |
| `rssi` | 最近信号强度 dBm |
| `lat`/`lon` | 飞机经纬度（有 Location 消息时） |
| `alt` / `spd` | 海拔 m / 水平速度 m/s（有则带） |
| `olat`/`olon` | 飞手(操作员)经纬度 |
| `proto` | 0=ASTM F3411 / 1=国标 CN 46750 |

## 五、文件说明

| 文件 | 说明 |
|------|------|
| `server.py` | 数据服务：串口读取 → WebSocket 广播 + 页面托管 + 演示模式 |
| `dashboard.html` | 智慧大屏页面（登录 / 高德地图 / 陌生警报 / 白名单，深色科技风） |
| `demo.html` | **独立演示大屏**：双击即开，内置 10 架无人机动画，功能与正式版一致 |
| `verify.py` | **页面自检**：`python verify.py` 一键检查两页关键功能与 JS 语法 |
| `requirements.txt` | 依赖：pyserial、websockets |

> 大屏页面为纯前端，不依赖任何框架；数据通道为 WebSocket，支持多窗口
> 同时打开。地图标绘：无人机=青色发光点+型号标签，飞手=绿色点，
> 虚线连接飞手↔飞机；点击标记/列表可选中并居中放大，右侧显示详情。
